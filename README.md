# WaterLab / 水实验

这是 WaterLab 0.5 的私有完整项目备份，网页尚未公开部署。

## 下载与运行

1. 下载仓库中的 [WaterLab-v05.zip](./WaterLab-v05.zip)。
2. 解压后打开 `WaterLab` 文件夹。
3. 在已安装 Node.js 的 Windows 电脑上双击 `Start Water Lab.cmd`；其他系统可运行 `node server.mjs`。
4. 浏览器打开 http://127.0.0.1:4174/ 。

压缩包保留完整目录结构，包含网页源码、内置模型、本地第三方依赖及许可、21 项自动检查与测试数据。支持 GLB、GLTF、OBJ + MTL、STL、PLY 网格导入，以及中英文界面。

项目文件、运行说明和技术比较均在压缩包内。源文件当前按 ZIP 归档保存，尚未展开为仓库目录。
